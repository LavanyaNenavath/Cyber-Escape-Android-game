# Cyber Escape Android Game

Cyber Escape is a cybersecurity-themed Android game developed using Kotlin and XML in Android Studio.

## Features
- Level 1: Password Breach
- Level 2: Vulnerability Hunt
- Level 3: Stop the Attack
- Timer-based challenges
- Score tracking
- Game Over and Win screens

## Technologies Used
- Kotlin
- Android Studio
- XML Layouts
- Android SDK

## Project Structure
- Main Menu
- Level Selection
- Three Game Levels
- Victory Screen
- Game Over Screen
